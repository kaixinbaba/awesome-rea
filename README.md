### Developer & security tools

- [OpenBSD netcat study](<https://github.com/NullLabTests/OpenBSD_netcat_REA>) — Static REA and Ghidra analysis of an OpenBSD netcat binary.
- [REA — Reverse Engineer Anything](<https://github.com/morluto/rea>) — Upstream CLI and MCP toolkit for agent-assisted software analysis.

### Games & game engines

- [DX-Ball](<https://github.com/N0zoM1z0/dx-ball>) — In-progress DX-Ball reconstruction using REA and Ghidra; original game files required.
- [TH04 bullet-ring reconstruction](<https://github.com/N0zoM1z0/th04>) — Focused REA study of TH04's bullet-ring behavior within a broader reconstruction.
- [OpenBattlefield2](<https://github.com/Moxnatiy/OpenBattlefield2>) — Incomplete Refractor 2 reimplementation with REA investigation tooling; original game required.
- [GunZRs](<https://github.com/OpenRsG/GunZRs>) — Rust game port with a separate REA investigation framework; original assets required.

### Audio, hardware & drivers

- [VSL-DSP](<https://github.com/grisuno/VSL-DSP>) — AudioBox VSL research and Linux tools, with REA contributing focused DSP findings.

### REA plugins, integrations & packaging

- [dsh-mcp-rea](<https://github.com/Ersith/dsh-mcp-rea>) — Community MCP bridge exposing a smaller selection of REA tools.
- [REA Investigator](<https://github.com/Devaretanmay/rea-investigate>) — Agent skill for planning, tracing, verifying and reporting REA investigations.
- [rea-jev](<https://github.com/juan-viox/rea-jev>) — REA plugin with Jev-based evidence checks; external model calls and fail-open hooks.
- [rea-agents Homebrew formula](<https://github.com/moonfruit/homebrew-tap/blob/main/Formula/rea-agents.rb>) — Community Homebrew formula for the upstream rea-agents package.

### Tutorials, case studies & resources

- [Notion clipboard bridge](<https://rea.tools/showcase/notion/>) — REA case study of Notion's clipboard pipeline, not a replacement app.
- [Aegis authenticator study](<https://rea.tools/showcase/aegis/>) — REA case study tracing code generation in the existing Aegis Android app.
- [DownUnderCTF flag checker](<https://rea.tools/showcase/ctf/>) — REA walkthrough of a DownUnderCTF reverse-engineering challenge.
- [rea-playbook](<https://github.com/jinshi666888/rea-playbook>) — Hands-on Electron lab with REA exercises and a separate offline demo.
- [rea-lab](<https://github.com/pablodiazjorge/rea-lab>) — Windows/Ghidra setup, practice challenges and ongoing REA evaluation work.
- [REA French community guide](<https://github.com/valorisa/Reverse-Engineer-Anything>) — Unofficial French guide to REA concepts, setup and investigation workflows.
- [Awesome AI Reverse Engineering](<https://github.com/DiscoverBox/awesome-ai-reverse>) — AI reverse-engineering tool list featuring REA, in Chinese and English.
- [Awesome Reverse Engineering](<https://github.com/morluto/awesome-reverse-engineering>) — Broad reverse-engineering tool and learning list from REA's maintainer.
