# Awesome REA

**English** · [简体中文](README.zh-CN.md)

Open-source reverse-engineering projects, reimplementations and compatible alternatives, plus [REA](https://github.com/morluto/rea) tools and resources. **REA usage is not required.**

### Games & game engines

- [DX-Ball](<https://github.com/N0zoM1z0/dx-ball>) — In-progress DX-Ball reconstruction using REA and Ghidra; original game files required.
- [TH04 bullet-ring reconstruction](<https://github.com/N0zoM1z0/th04>) — Focused REA study of TH04's bullet-ring behavior within a broader reconstruction.
- [OpenBattlefield2](<https://github.com/Moxnatiy/OpenBattlefield2>) — Incomplete Refractor 2 reimplementation with REA investigation tooling; original game required.
- [GunZRs](<https://github.com/OpenRsG/GunZRs>) — Rust game port with a separate REA investigation framework; original assets required.
- [OpenRCT2](<https://github.com/OpenRCT2/OpenRCT2>) — RollerCoaster Tycoon 2 engine reimplementation; original game files required.
- [OpenMW](<https://github.com/OpenMW/openmw>) — Morrowind engine and editor reimplementation; original game data required, mod compatibility varies.
- [OpenTTD](<https://github.com/OpenTTD/OpenTTD>) — Transport Tycoon Deluxe-style simulation with optional free graphics, sound and music.
- [ScummVM](<https://github.com/scummvm/scummvm>) — Replacement engines for supported classic adventures and RPGs; original game data usually required.
- [free-heroes4 (openh4)](<https://github.com/tallowmere/free-heroes4>) — Unfinished Heroes of Might and Magic IV engine and inspection tools; original GOG game data required.
- [Rook](<https://github.com/AsyncFinn/rook>) — Early Rust Roblox-engine reimplementation for local places and Luau scripts; not a Roblox server client.
- [rct3++](<https://github.com/tomast1337/rct3pp>) — Early RollerCoaster Tycoon 3 format tools and viewer; original game required, not a complete playable engine.
- [OpenRealm](<https://github.com/corepunch/open-realm>) — Quake-style engine for Blizzard-era data with Warcraft III as the main playable target; original MPQ assets required.
- [Jazz² Resurrection](<https://github.com/deathkiller/jazz2-native>) — C++ reimplementation of Jazz Jackrabbit 2 with wide platform ports; original game files required.
- [Ruffle](<https://github.com/ruffle-rs/ruffle>) — Adobe Flash Player emulator in Rust for desktop and the web; ActionScript support still has gaps.
- [nv-rs](<https://github.com/slaterain/nv-rs>) — From-scratch Fallout: New Vegas reimplementation in Rust/Bevy; original Data folder required.
- [OpenRA](<https://github.com/OpenRA/OpenRA>) — Libre Westwood RTS engine with Red Alert, Tiberian Dawn and Dune 2000 mods; not an EA remaster.
- [OpenXcom](<https://github.com/OpenXcom/OpenXcom>) — Open-source clone of X-COM: UFO Defense and Terror From the Deep; vanilla original resources required.
- [OpenLoco](<https://github.com/OpenLoco/OpenLoco>) — C++ reimplementation of Chris Sawyer's Locomotion; original game assets required.
- [openblack](<https://github.com/openblack/openblack>) — Modern C++ reimplementation of Black & White (2001); original game assets required, not redistributed.
- [Daggerfall Unity](<https://github.com/Interkarma/daggerfall-unity>) — Unity recreation of The Elder Scrolls II: Daggerfall; free DOS Daggerfall assets required.
- [PvZ-Portable](<https://github.com/wszqkzqk/PvZ-Portable>) — Cross-platform Plants vs. Zombies GOTY reimplementation; original GOTY assets required.
- [dethrace](<https://github.com/dethrace-labs/dethrace>) — Carmageddon (1997) engine rebuild via symbol-driven RE; original game data required.
- [Metaforce](<https://github.com/AxioDL/metaforce>) — Metroid Prime engine reimplementation on matching decomp; builds currently unavailable.
- [OpenLara](<https://github.com/XProger/OpenLara>) — Classic Tomb Raider open-source engine; original game data required.
- [OpenGOAL](<https://github.com/open-goal/jak-project>) — Jak & Daxter GOAL decompile and native x86-64 PC ports; PS2 retail disc required.
- [SiegeFX](<https://github.com/codingncaffeine/SiegeFX>) — Clean-room Dungeon Siege (2002) reimplementation in C#/.NET; original .dsres data required.
- [legend-of-legaia-re](<https://github.com/AndrewAltimit/legend-of-legaia-re>) — PSX Legend of Legaia reverse engineering and Rust port; BYO disc, no Sony assets.
- [CorsixTH](<https://github.com/CorsixTH/CorsixTH>) — Theme Hospital (1997) reimplementation with modern OS/HD support; original assets required.

- [VectorCraft](<https://github.com/storytold/vectorcraft>) — Alpha-stage Illustrator-style vector illustration in Rust.
- [FilmCraft](<https://github.com/storytold/filmcraft>) — Alpha-stage Premiere-style video editing, color and sound in Rust.

- [PdfCraft](<https://github.com/storytold/pdfcraft>) — Alpha-stage Acrobat-style PDF viewing, organization, annotation and forms.

- [DesignCraft](<https://github.com/storytold/designcraft>) — Pre-alpha InDesign-style page layout and publishing in Rust.
- [FigCraft](<https://github.com/storytold/figcraft>) — Early-alpha clean-room Figma-style interface design in Rust; not a drop-in Figma replacement.

- [DeckCraft](<https://github.com/storytold/deckcraft>) — Alpha-stage PowerPoint-style slide editing and presentations in Rust.

### Audio, hardware & drivers

- [VSL-DSP](<https://github.com/grisuno/VSL-DSP>) — AudioBox VSL research and Linux tools, with REA contributing focused DSP findings.
